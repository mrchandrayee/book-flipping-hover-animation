A runnable recreation of the book/page flip interaction shown in the supplied screen recording.

## Features
- Two-tone purple and pink book covers with a grey turning page.
- 3D page flip on hover and keyboard focus.
- CSS `perspective`, `transform-style`, `backface-visibility`, and `transform-origin`.
- Responsive layout and reduced-motion support.
- No JavaScript or package installation required.

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python -m http.server 8000
```

Visit http://localhost:8000

## Files

- `index.html` — semantic page structure
- `style.css` — layout, colors, and 3D flip animation

## Reconstruction note

The video contains small, partially legible source-code panels. This project reconstructs the visible result and the discernible CSS 3D page-flip behavior; it is not a verbatim copy of the creator's complete original source.
